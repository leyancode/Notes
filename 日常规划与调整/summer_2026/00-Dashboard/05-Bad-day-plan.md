# Bad Day Plan

## Rule

Bad days are for damage control, not comeback.

Today only needs to avoid breaking the chain.

## Minimum Tasks

### 1. Project

Do 45-90 minutes only.

Choose one:
- Check one experiment log
- Organise one result file
- Write 3 lines in Project Log
- Fix one small script issue
- Read one PETSc / ARCHER2 note
- List tomorrow's experiment
- Write one paragraph for dissertation

Minimum:
- Open project folder
- Work 45 minutes
- Write next step

### 2. Job

Do one small action only.

Choose one:
- Save one job
- Edit one CV bullet
- Add one row to Job Tracker
- Read one job description
- Write one project bullet
- Research one company

Minimum:
- One job-related record

### 3. English

Speak for 1 minute.

Choose one:
- Tell me about yourself
- My PETSc project
- What is strong scaling?
- Why HPC / RSE?
- A difficult bug I solved

Minimum:
- Record 1 minute
- No need to replay

### 4. Body

Move for 20 minutes.

Choose one:
- Walk outside
- Walk on treadmill
- Easy cycling
- Stretching
- Light gym session

Minimum:
- Leave the chair
- Move 20 minutes

## Do Not

- Do not redesign the whole life plan
- Do not compare with others
- Do not scroll anxiety content
- Do not start random new courses
- Do not stay up late to compensate
- Do not throw away the whole system because of one bad day
