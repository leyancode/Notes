## 10:00 到 12:30 论文 / HPC 项目核心工作

这是一天最重要的时间。  
这段时间只做 dissertation / PETSc / HPC benchmark。

不要突然去学算法。  
不要突然去刷八股。  
不要突然去研究前端。  
不要突然觉得自己 C++ 太菜然后开一本 800 页的书。

你现在最重要的是：

> **把项目推进到能写进论文、能放进 CV、能在面试里讲清楚。**

你的项目可以这样收缩：

**Benchmark selected PETSc Krylov solvers and preconditioners for sparse linear systems on ARCHER2.**

别把题目搞成“Benchmark PETSc”。  
那太大了，像要把海喝干。

你只需要每天推进其中一个小东西：

今天明确 benchmark case。  
明天跑一个小规模实验。  
后天整理 log。  
再后天画 runtime 图。  
然后写一点 interpretation。

你需要的是闭环：

```
run experiment -> collect log -> parse result -> plot figure -> explain result
```

这条链跑起来，你的论文和求职材料就都有了。

> **稳定精神状态，改善体型，增强自信，让自己能长期执行。**

一周这样安排：

周一：上肢推

```
4 次力量 + 1 次恢复训练
```

比你硬练 5 次更适合现在的你。

训练原则：

每个动作 3 组。  
每组 8 到 12 次。  
重量选最后 2 次有点难，但动作不变形。

别第一周就猛加重量。  
你不是去证明自己是男人。  
你是去把身体系统修好。

## 关于签证

你说签证到 2027 年 2 月，且毕业后能申请 Graduate Route。这个确实给了你喘息空间。英国官方 Graduate visa 页面目前仍说明，申请者通常需要已经成功完成当前 Student visa 对应课程，硕士学位属于通常符合的课程类型；申请需要在线完成，并且通常申请后 8 周内出结果。

但你别把“还早”理解成“可以先瘫三个月”。  
你的优势窗口是现在到毕业后这几个月：论文、项目、CV、投递、面试口语，全都能叠起来。

如果你偏向回国/香港，Graduate Route 可以当后备缓冲，不一定是主线。你现在应该两边都铺：

香港主投。  
英国保底投。  
国内如果愿意，也可以放第三梯队。
