# 状态差保底计划

适用情况：

```
睡少了很焦虑很累心情很差拖延了一上午不想学习不想健身感觉自己废了
```

这时候不要想着“今天必须追回来”。  
你只要完成下面 5 件事，这一天就算过关。

---
 
# 状态差当天的极简时间表

如果一整天都很烂，就用这个：

```
10:30 起床 / 洗漱 / 吃点东西
11:00 项目 45 分钟
12:00 午饭
14:30 求职小动作 15 分钟
15:00 英语录音 1 分钟
17:00 走路 20 分钟
21:30 写 5 行复盘
00:00 前睡
```

如果你已经拖到了下午，就用这个：

```
15:00 项目 45 分钟
16:00 求职小动作 15 分钟
16:30 英语 1 分钟
17:30 走路 20 分钟
21:30 写明天第一件事
```

如果你已经拖到了晚上，就用这个：

```
20:30 项目 25 分钟
21:00 求职保存 1 个岗位
21:10 英语说 1 分钟
21:20 拉伸 / 走路 10 分钟
21:40 写明天第一件事
```

晚上版本做完就停。  
不要半夜突然热血上头补偿自己。

---

## 1. 项目：只做 45 到 90 分钟

不要做复杂任务。  
不要开新坑。  
不要逼自己理解一大堆文档。

只选一个低难度任务：

```
整理昨天的实验 log检查一个 Slurm 输出文件改一个 README 小段写 3 行 Project Log列出明天要跑的实验看 1 个 PETSc 参数画一张已有数据的草图整理一个报错信息
```

状态差时，项目目标不是“大推进”。  
目标是：

> **让项目没有断。**

最低标准：

```
打开项目文件夹做 45 分钟写下 Next step
```

做到这三件事就够。

---

## 2. 求职：只做 1 个小动作

不要投很多。  
不要刷一堆岗位。  
不要突然怀疑自己适不适合这个世界。

只做一个动作：

```
保存 1 个岗位修改 1 条 CV bullet整理 1 个公司名字看 1 个岗位要求把一个项目经历写成 3 行更新 Job Tracker 1 行
```

最低标准：

```
求职有一个记录
```

今天没投递也可以。  
只要没有完全断掉，就算赢。

---

## 3. 英语：只说 1 分钟

不要背稿。  
不要纠结语法。  
不要嫌自己口音难听。

拿手机录 1 分钟，说其中一个主题：

```
Tell me about yourself.My PETSc project.What is strong scaling?Why am I interested in HPC?A difficult bug I solved.
```

说得烂也没关系。  
状态差的时候，英语目标不是变流利。

目标是：

> **让嘴巴保持工作状态。**

最低标准：

```
录音 1 分钟不用回听也行
```

---

## 4. 身体：只动 20 分钟

状态差时不要逼自己练完整训练。

只做一个：

```
出门走 20 分钟去健身房踩车 20 分钟跑步机慢走 20 分钟做 10 分钟拉伸 + 10 分钟散步在家做俯卧撑 / 深蹲 / 平板支撑各一点
```

最低标准：

```
离开椅子动 20 分钟
```

你不是在健身。  
你是在把自己从情绪泥潭里拔出来一点。

---

## 5. 晚上：只写 5 行复盘

不要写长篇自责。  
不要写“我为什么这么废”。  
不要审判自己。

只写：

```
## Bad Day Log - YYYY-MM-DDProject:- Job:- English:- Body:- Tomorrow first task:- 
```

最后一行最重要。  
你只需要给明天留一个入口。

# 状态差时绝对不要做的事

```
不要重新制定人生计划不要看同龄人成功案例不要刷求职焦虑帖不要打开一堆课程不要熬夜补进度不要因为今天差就推翻整个系统不要在焦虑时乱投简历不要在焦虑时乱花钱不要在焦虑时乱交易
```
