# Python 字符串常用处理：不可变、清洗、查找、替换、格式化

日常写代码有一大半时间在搬字符串：**去掉用户多敲的空格、统一大小写再比较、判断开头结尾、找子串、拼错误信息**。这些方法都很简单，坑却密集且**几乎全是静默的**——用错了不报错，只是安静地给你一个不对的字符串。

本篇是"除切分外"的常用方法总览；**切分家族**（`split` / `rsplit` / `splitlines` / `partition` / `join`）内容多，单独放在 [python-split.md](python-split.md)，本篇只给索引。

---

## 思路

一切的地基是一句话：**Python 的字符串不可变（immutable）**。

所以字符串"方法"没有一个是**修改**字符串的——它们全都**造一个新的返回给你**，原来那个一个字节没动。看不懂这一点，就会写出"我明明 strip 了怎么还有空格"的经典 bug。

> [!tip]- 核心思路
> **所有字符串方法都返回新字符串；不接住返回值，等于什么都没做。**
>
> ```python
> s = "  hi  "
> s.strip()        # 'hi'  ← 这是新造的，你没接住，转头就被丢了
> print(s)         # '  hi  '   原字符串纹丝不动
>
> s = s.strip()    # ✅ 必须赋值回去
> print(s)         # 'hi'
> ```
>
> 判断依据：看到 `s.某方法()` 单独占一行、前面没有 `=`，**基本可以断定是 bug**（除了 `print`、`append` 这类真有副作用的）。

由不可变还能推出两条实用结论：**方法可以链式串起来**（`s.strip().lower()`，每一步都拿上一步的新串继续），以及**循环里 `s += x` 是 $O(n^2)$**（每次都复制整个字符串），拼接一律用 `join`。

## 1. 导入与创建

全是 `str` 自带方法，**无需 import**。只有"多种分隔符 / 模式匹配"才需要 `re`。

> [!success]- 基础语法
> ```python
> raw = "  Hello, World!\n"
>
> raw.strip()             # 'Hello, World!'   去两头空白
> raw.strip().lower()     # 'hello, world!'   链式
> raw.strip().startswith("Hello")   # True
> raw.replace("World", "Python")    # '  Hello, Python!\n'
> f"{raw.strip()!r}"      # "'Hello, World!'"  带引号，调试用
> ```

## 2. 去空白与去前后缀：`strip` 家族（**含最大的坑**）

| 方法 | 作用 |
| --- | --- |
| `s.strip()` | 去掉**两头**的空白（空格、`\t`、`\n`、`\r`） |
| `s.lstrip()` / `s.rstrip()` | 只去左边 / 只去右边 |
| `s.strip(chars)` | 去掉两头**属于 `chars` 这个字符集合**的字符 |
| `s.removeprefix(p)` / `s.removesuffix(p)` | 去掉**完整的**前缀 / 后缀（Python 3.9+） |

> [!warning]- 最大的坑：`strip(chars)` 参数是**字符集合**，不是前后缀
> 它会把参数拆成一个个**字符**，然后从两头啃，**只要碰到属于这个集合的字符就继续啃**，直到遇见不属于的为止。实测：
>
> ```python
> "test.txt".strip(".txt")     # 'es'      😱 不是 'test'
> "banana".strip("ba")         # 'nan'     😱 不是 'nana'
> ```
>
> `".txt"` 被拆成 `{'.', 't', 'x'}`：左边 `t` 中招被啃掉、`e` 不在集合里停下；右边 `t`、`x`、`t`、`.` 连着被啃掉、`s` 停下 —— 于是只剩 `'es'`。
>
> **要去掉一个完整后缀，用 `removesuffix`**：
> ```python
> "test.txt".removesuffix(".txt")   # ✅ 'test'
> ```
> 记法：**`strip` 啃的是"字符"，`removesuffix` 削的是"那一串"。**

### 三个真实用途

```python
line = "config.json\n"
line.rstrip("\n")            # 逐行读文件时去掉行尾换行

user_input = "  alice  "
user_input.strip()           # 用户复制粘贴时常带首尾空格

key, _, value = "timeout = 30".partition("=")
key.strip(), value.strip()   # ('timeout', '30')  配置行两边都要清
```

**本项目** —— [`hpc_agent/llm_config.py:40`](../../hpc_agent/llm_config.py) 读环境变量后 `.strip()`：终端里复制 API key 极易在末尾带一个换行或空格，不清掉就是一个"key 明明是对的却认证失败"的噩梦级 bug。[`evals/run_eval.py:42`](../../evals/run_eval.py) 用 `if line.strip()` 过滤 JSONL 空行——**这正是 [python-split.md](python-split.md) 里"空串不对称"那条坑的标准解法**：不判空，`json.loads("")` 就会炸。

## 3. 大小写：比较之前先归一化

```python
"Admin".lower()        # 'admin'
"admin".upper()        # 'ADMIN'
"ß".lower()            # 'ß'    ← 德语 eszett，lower 拿它没办法
"ß".casefold()         # 'ss'   ← casefold 更彻底，专为"忽略大小写比较"设计
```

**规则**：给人看的输出用 `lower`/`upper`；**做不区分大小写的比较**用 `casefold`（纯 ASCII 时两者等价，涉及非英文才见分晓）。

> [!warning]- `title()` 的撇号坑
> ```python
> "it's ok".title()      # "It'S Ok"   😱 撇号后面的字母也被大写了
> ```
> `title()` 认为"非字母之后就是新单词的开头"。**别用它处理人名**（`o'brien`、`mcdonald` 全会出错），改用 `capitalize()`（只大写第一个字母）或按业务规则自己处理。

**关键纪律**：归一化只是为了**比较**，别把归一化后的值存回原数据。

```python
headers = {"X-API-KEY": "abc"}
[k for k in headers if "key" in k.lower()]   # ['X-API-KEY'] ← 原键名保持不变
```

**本项目** —— [`hpc_agent/router.py:103`](../../hpc_agent/router.py) 的 `question_low = question.lower()`：判断问题里有没有 `hybrid`/`mpi` 之前先转小写，用户写 `MPI` 还是 `mpi` 都能命中；但**返回给下游的仍是原问题**。

## 4. 查找与判断

| 需求 | 写法 | 找不到时 |
| --- | --- | --- |
| 只想知道有没有 | `"ab" in s` | 返回 `False` ✅ 首选 |
| 要知道位置 | `s.find("ab")` | 返回 **`-1`** |
| 要知道位置，找不到算错误 | `s.index("ab")` | 抛 `ValueError` |
| 从右边找 | `s.rfind` / `s.rindex` | 同上 |
| 开头 / 结尾 | `s.startswith(p)` / `s.endswith(p)` | 返回 `False` |
| 出现几次 | `s.count("ab")` | 返回 `0` |

> [!warning]- 经典 bug：`find` 返回 `0` 是"找到了"，但 `if` 认为是假
> ```python
> s = "abc"
> if s.find("a"):        # ❌ find 返回 0（在第 0 位找到了），0 是 falsy → 判断失败
>     print("找到了")     #    这行永远不会执行
>
> if s.find("a") != -1:  # ✅ 显式比较
> if "a" in s:           # ✅✅ 更好——只想知道有没有，就别用 find
> ```
> 这和 [worked-examples.md §4](worked-examples.md) 的 `if not discount` 是同一族坑：**`0` 是合法结果，却和"没有"共用了假值。**

> [!tip]- `startswith` / `endswith` 可以传**元组**，一次判断多个
> ```python
> path = "~/data/a.txt"
> path.startswith(("/", "~"))          # True —— 绝对路径或家目录
> name.endswith((".jpg", ".png"))      # True —— 多种扩展名
> ```
> 比 `s.startswith("/") or s.startswith("~")` 干净得多。注意必须是**元组**，列表会 `TypeError`。

## 5. 内容判定：`isX` 家族

```python
"123".isdigit()      # True
"abc".isalpha()      # True
"a1".isalnum()       # True
" ".isspace()        # True
"".isspace()         # False   ← 空串在所有 isX 里都是 False
```

**空串的真假**：`bool("")` 是 `False`，所以判断"有没有内容"直接 `if not s:` 就行，不用 `len(s) == 0`。但要小心 `"  "`（全空格）是**真值**——想判断"实质为空"得先 `strip`：

```python
if not s.strip():     # 空串、全空格、纯换行都算空
    ...
```

⚠️ `isdigit` / `isdecimal` / `isnumeric` 三者的区别是个独立的坑（全角数字、上标 `²`），已讲过[[python-numberType]]，这里不重复。

## 7. 替换

```python
"a-b-c".replace("-", "+")        # 'a+b+c'   默认替换**全部**
"a-b-c".replace("-", "+", 1)     # 'a+b-c'   只替第一个
"abc".replace("z", "!")          # 'abc'     找不到 → 原样返回，**不报错**
```

> [!warning]- `replace` 找不到时是静默的
> 它不会告诉你"没替成"。如果"必须替换成功"是业务前提，**得自己检查**：
> ```python
> if old not in text:
>     raise ValueError(f"模板里找不到占位符 {old!r}")
> text = text.replace(old, new)
> ```
> 否则模板改了个字，你的渲染逻辑会安静地输出没替换的原文。

**链式替换要当心顺序**——前一次的产物会成为后一次的输入：

```python
"a".replace("a", "b").replace("b", "c")   # 'c'  两次都命中了，不是 'b'
```

## 8. 格式化：f-string

```python
name, ratio, n = "hybrid", 3.14159, 1000000

f"{name} 快 {ratio:.2f} 倍"    # 'hybrid 快 3.14 倍'    保留两位小数
f"{n:,}"                       # '1,000,000'            千分位
f"{name!r}"                    # "'hybrid'"             带引号（repr）
f"{n:>10}"                     # '   1000000'           右对齐宽 10
f"{5:03d}"                     # '005'                  补零（等价 "5".zfill(3)）
f"{ratio=}"                    # 'ratio=3.14159'        调试神器（3.8+）
```

> [!tip]- `!r` 什么时候用：**写错误信息时几乎必用**
> ```python
> name = ""
> f"unknown router: {name}"     # 'unknown router: '     ← 空的？还是漏打了？看不出来
> f"unknown router: {name!r}"   # "unknown router: ''"   ← 一眼看出是空字符串
> ```
> `!r` 调用 `repr()`，给字符串加上引号、把 `\n` 显示成 `\n` 而不是真换行。**报错信息里的值一律用 `!r` 包起来**，否则"值里有空格/换行/是空串"这些最需要看见的情况恰恰看不见。
>
> **本项目** —— [`hpc_agent/router.py:145`](../../hpc_agent/router.py) 的 `f"unknown router: {name!r} ..."` 就是这个习惯。

## 9. 按"我想干什么"速查

| 我想…… | 写法 |
| --- | --- |
| 去掉用户多敲的空格 | `s.strip()` |
| 去掉行尾换行 | `s.rstrip("\n")` |
| 去掉一个完整后缀 | `s.removesuffix(".txt")` ← **不是 `strip`** |
| 不区分大小写比较 | `a.casefold() == b.casefold()` |
| 判断有没有子串 | `"x" in s` ← 不要用 `find` |
| 判断开头/结尾（多选一） | `s.startswith(("/", "~"))` |
| 判断"实质为空" | `if not s.strip():` |
| 替换全部 / 只替第一个 | `s.replace(a, b)` / `s.replace(a, b, 1)` |
| 拼错误信息里的值 | `f"...{value!r}..."` |
| 数字补零 / 对齐 | `f"{n:03d}"` / `f"{s:>10}"` |
| 路径取最后一段 | `Path(s).name` ← **不要用字符串方法** |
| 拼接一个列表 | `sep.join(parts)` ← **不要 `+=`** |

## 10. 常见易错点

> [!warning]- 易错点
> - **忘了赋值回去**（第一名）：`s.strip()` 单独一行等于没执行。字符串不可变，方法只返回新串。
> - **`strip(".txt")` 当成去后缀**：它是字符集合，实测 `"test.txt".strip(".txt")` → `'es'`。用 `removesuffix`。
> - **`if s.find(x):`**：找到在第 0 位时返回 `0`，被当成假。用 `in` 或显式 `!= -1`。
> - **`replace` 找不到不报错**：必须成功的替换要自己校验。
> - **`title()` 处理人名**：`"it's ok".title()` → `"It'S Ok"`。
> - **比较前忘了归一化大小写**，或者反过来——**把归一化后的值存回了原数据**（原始大小写就永久丢了）。
> - **`"  "` 是真值**：判断"空内容"要 `if not s.strip()`。
> - **循环里 `s += x`**：$O(n^2)$，用 `join`。
> - **`startswith` 传列表**：必须是元组，`["a","b"]` 会 `TypeError`。

---

## 复杂度

> [!summary]- 复杂度
> - `strip` / `lower` / `replace` / `join`：$O(n)$，且**都会分配一个新字符串**（空间 $O(n)$）。
> - `in` / `find`：平均 $O(n)$，最坏 $O(n \times m)$（$m$ 为被找的子串长度）。
> - `startswith` / `endswith`：$O(m)$，只看开头/结尾那一小段——比 `s[:len(p)] == p` 更省，也更不容易写错边界。
> - **反面**：循环里 `result += part` 是 $O(n^2)$，因为不可变导致每次都整体复制。

---

## 一句话总结

字符串**不可变**，所有方法都返回新串、不接住就白干；清洗记住 `strip` 啃的是**字符集合**（去完整后缀要用 `removesuffix`），比较前用 `casefold` 归一化、但别把归一化结果存回原数据，判断有没有子串直接用 `in`（`find` 的 `0` 会骗过 `if`），错误信息里的值一律 `!r`。

## 模板归纳

```python
# 清洗一行输入
line = raw.strip()
if not line:                      # 空串 / 全空格 / 纯换行
    continue

# 不区分大小写的成员判断
if value.casefold() in {"yes", "y", "true"}:
    ...

# 多种前缀/后缀一次判断
if name.endswith((".jpg", ".png", ".webp")):
    ...

# 必须成功的替换
if placeholder not in template:
    raise ValueError(f"模板缺少占位符 {placeholder!r}")
result = template.replace(placeholder, value)

# 错误信息：值一律 !r
raise ValueError(f"unknown router: {name!r} (expected 'rule' or 'llm')")
```
