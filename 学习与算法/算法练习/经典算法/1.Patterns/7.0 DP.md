# 动态规划 DP 总览

## 一句话定位

DP = **带记忆的递归**。先用回溯的「选/不选」写出递归，发现子问题**重复且可复用**，就把递归塌缩成记忆化 / 递推。所以 DP 不是新东西，是回溯的「省钱版」。

## 什么时候能用：两把尺

> [!tip]- 重叠子问题 + 无后效性
> 
> - **重叠子问题**（值不值得）：递归树里同一参数的节点反复出现 → 缓存一次、后续查表，指数塌缩为多项式。
> - **无后效性**（能不能）：`dfs(状态)` 的返回值只由参数决定，与「从哪条路径来、之前做过什么」无关 → 参数即**状态**，可按参数缓存。
> 
> 判据一句话：**递归函数的参数，是否已经完整刻画了状态？** 是→能缓存；否→参数没写全，缓存会串味（如排列题依赖 `path`，只能回溯）。详见 [[重叠子问题与无后效性]]。

## 通用解题流程

> [!success]- 五步：定义 → 转移 → 边界 → 记忆化 → 递推
> 
> 1. **定义合同**：`dfs(状态) = 在这个状态下的最优值 / 方案数`。状态就是「刻画当前局面所需的最少参数」。
> 2. **写转移**：对当前元素分类讨论（最常见是「选/不选」），保证**不重不漏**，用 `combine` 合并子问题：$dfs(i)=combine(\text{各分支})$。
> 3. **定边界**：`base case` 是合同在边界处的取值——先算语义（空集该返回什么），再检查转移「最多往回退几步」，边界就得盖住几格。
> 4. **加记忆化**：确认无后效性后套 `@cache` 或手写 `memo`，递归就变 DP。
> 5. **翻递推 / 压空间**（进阶）：看清依赖方向后自底向上写循环，必要时用滚动变量把空间降到 $O(1)$。
> 
> `combine` 选谁看题目要什么：求最值→`max`/`min`；求方案数→`+`。空集的 base 也随之变：最值通常 `0`（或 `inf` 表不可达），计数通常 `1`（唯一空方案）。

## 学习与求职优先级（重要）

> [!tip]- 三层投入：递归打底 → 一维会写 → 滚动了解
> 
> 面试与笔试的性价比排序，按这三层分配精力：
> 
> | 层级 | 内容 | 要求 |
> | --- | --- | --- |
> | **必须能默写** | 递归 + `@cache`（状态定义、转移、base） | 推导清晰、白板一次写对，面试官最爱看 |
> | **应该能写** | **一维空间优化**（背包正序/倒序、滚动变量） | OA/笔试标准答案常是一维，面试常追问「能否压空间」 |
> | **了解即可** | 二维完整版当桥梁、`%2` 滚动数组 | 看懂即可，落笔直接写递归或一维 |
> 
> 结论：**「递归最稳」判断正确**，但别把一维优化整体划到「了解即可」——它不难（递归的机械翻译 + 一句方向规则），却是高频考点，值得提到第二层「能写」。真正的边角是 `%2` 滚动这类过渡写法。

## 通用模板

```python
from functools import cache

@cache
def dfs(state):
    if is_base(state):
        return BASE            # 最值:0/inf；计数:1/0
    return combine(dfs(next_1), dfs(next_2), ...)  # 对当前元素不重不漏地分类
# 入口：把定义里的"状态"替换成"完整问题"对应的值，如 dfs(n-1) 或 dfs(n)
```
