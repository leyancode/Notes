**1. process** **是什么？**

- **process****（进程）**：操作系统层面的概念
- 每个 MPI 程序启动后，会有 **多个独立的进程**
- 每个进程：
    - 有自己独立的地址空间
    - 跑同一份程序
    - 但数据不同

在 MPI 中：  
**一个** **MPI process ≈** **一个** **OS process**
 
**2. rank** **是什么？**

- **rank** **不是进程本身**
- rank 是：￼一个进程在某个 communicator 里的**编号（****ID****）**
 
MPI_Comm_rank(MPI_COMM_WORLD, &my_rank);￼  
含义是：

- 在 MPI_COMM_WORLD 这个通信域里
- 当前进程的编号是 my_rank
- rank 范围是：0 ... (size-1)

**关键点**

- 同一个进程：
    - 在不同 communicator 里，可以有不同 rank
- rank 是 MPI 语义，不是 OS 语义
 
**3. root** **是什么？**

- **root** **不是一个****“****特殊进程类型****”**
- root = **你在** **collective** **调用里指定的某个** **rank**

例如：
 
MPI_Reduce(..., root=0, MPI_COMM_WORLD);￼  
含义是：

- rank == 0 的那个进程
- 在这次 MPI_Reduce 中扮演 root 的角色
- 只有它会收到最终结果

👉 root **只是一个参数，不是函数、不是变量、不是进程类型**
 
**一句话总结（考试用）**  
An MPI process is an operating system process, while a rank is the identifier of a process within a communicator.  
The root is the process with a specific rank designated to receive the result of a collective operation.￼￼

**Construction: MPI_Op_create**  
**创建自定义归约算子**

![Exported image](Exported%20image%2020260730160725-9.png)

函数原型（Construction）：  
int MPI_Op_create(MPI_User_function* user_function,￼ int commutativity,￼ MPI_Op* handle);  
#include \<mpi.h\>  
#include \<stdio.h\>
 
static void my_sum(void* a, void* b, int* len, MPI_Datatype* dtype) {  
int n = *len;  
int* ia = (int*)a;  
int* ib = (int*)b; // ib 是 inout：输入+输出  
for (int i = 0; i \< n; i++) ib[i] += ia[i];  
}
 
int main(int argc, char** argv) {  
MPI_Init(&argc, &argv);
 
int rank;  
MPI_Comm_rank(MPI_COMM_WORLD, &rank);
 
MPI_Op op_sum;  
==MPI_Op_create(my_sum, /*commutative=*/1, &op_sum);==
 
int x = rank + 1; // 每个进程一个整数  
int y = 0; // root 接收结果
 
MPI_Reduce(&x, &y, 1, MPI_INT, op_sum, 0, MPI_COMM_WORLD);
 
if (rank == 0) printf("sum = %d\n", y);
 
MPI_Op_free(&op_sum);  
MPI_Finalize();  
return 0;  
}
   

- MPI_User_function* user_function￼指向你编写的 user-defined reduction function（自定义归约函数）
- ==int commutativity====￼====指示该== ==operator== ==是否== **commutative**==（可交换）====￼====典型取值：====true / false====（在== ==C== ==里通常用== ==1 / 0====）==

- MPI_Op* handle￼输出参数，返回创建好的 operator 句柄（handle），之后在 MPI_Reduce / MPI_Allreduce 等中使用
 
**Precondition**  
**前置条件：必须满足** **associative****（结合律）**

![Exported image](Exported%20image%2020260730160726-10.png)

==你定义的== ==reduction operator== ==必须是== **associative**==（可结合的）。==  
设自定义 operator 为 ⊕，则必须满足：  
(A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)

- MPI 的 reduction 可能采用 tree-based reduction、分层合并等策略
- 合并顺序不固定时，只有满足结合律才能保证最终结果一致（或至少语义正确）
 
**Clarification**  
**commutativity** **参数的含义与顺序保证**

- 你提供的 operator 必须是 **commutative**（可交换）
- 即还需要满足：A ⊕ B = B ⊕ A

- MPI 将按照 **ascending order of MPI process rank**（按进程 rank 递增顺序）组合 operands
- 也就是说运算顺序被规定，用于处理 non-commutative 的情况

备注：标准参考 MPI v4.0 Section 6.9.5
 
**Prototype of the user-defined function**  
**用户自定义归约函数的接口规范**

![Exported image](Exported%20image%2020260730160727-11.png)

类型定义（Prototype）：  
typedef void MPI_User_function(void* elements_a,￼ void* elements_b,￼ int* length,￼ MPI_Datatype* datatype);

- elements_a￼来自“第一个 MPI process”的输入元素（本次局部归约中的一方 operands）
- elements_b￼来自“第二个 MPI process”的输入元素￼同时也是 output buffer：你必须把本次归约结果写回到 elements_b
- length￼每个进程发送的元素个数￼同时也是 elements_a 与 elements_b 两个数组的长度￼你的函数需要按 *length 循环处理所有元素
- datatype￼描述元素类型（例如 MPI_INT、MPI_DOUBLE，或你自定义的 derived datatype）￼通常用来决定如何 cast elements_a/b
 
**Implementing a SUM operator**  
**实现一个** **sum** **类型** **operator** **时的关键注意点**

![Exported image](Exported%20image%2020260730160728-12.png)

- elements_b 不只是输入，它还必须在函数结束时包含本次 reduction 的结果
- 换句话说，elements_b 是 inout buffer

- 读取 elements_a[i] 和 elements_b[i]
- 计算合并结果
- 写回 elements_b[i]

如果你只计算但不写回 elements_b，MPI 得不到正确的归约结果。
 
**FAQ: Is length an int*, or int?**

- ==MPI_User_function== ==的第三个参数类型是== **int***==，不是== ==int==
- ==原因：为了兼容== **FORTRAN bindings**==（====Fortran== ==接口约定）==

==实际使用时通常写== ==*length== ==作为真实长度。==￼￼

- length：是一个 **指针**
- *length：是这个指针指向的 **真实整数值****￼**

**&length** **和** ***length** **的区别（非常重要）**  
假设：
 
- p → 地址
- *p → 5（值）
- &p → 指针 p 自己的地址（几乎从不用）

- MPI 给你的是 int* length
- 你要的是 **值** → *length
