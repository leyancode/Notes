**DMP Online Outline** **（****DMP Online** **概览）**

- **Digital Curation Centre (DCC)****￼**英国高等教育机构中的研究数据管理（Research Data Management, RDM）中心
- **DMP Online**
    - 由 **DCC** 设计的工具
    - 自动化生成并访问有效的 **Data Management Plans**
    - 高度可定制（Very customisable）
    - 注册入口: [https://dmponline.ed.ac.uk/](https://dmponline.ed.ac.uk/)
 
**使用步骤（****Steps to Use DMP Online****）**

1. 点击 **“Create Plan”****￼**创建一个新的计划
2. 填写 **Information about you and the project**
    - 关于个人与项目的信息
    - 包括研究者姓名、机构、项目名称等基本内容

**1. Information about data & data formats**  
**1.1 Description of data to be produced** **（将要产生的数据类型）**

- Experimental （实验数据）
- Observational （观测数据）
- Raw or derived （原始或衍生数据）
- Physical collections （实体收集品）
- Models and their outputs （模型及其输出）
- Simulation outputs （模拟结果）
- Curriculum materials （课程资料）
- Software （软件）
- Images （图像）
- 其他（etc.）
 
**1.2 File formats** **（文件格式）**

- **Specification** （具体格式）
- **Justification** （选择理由）

**1.3 Data volumes** **（数据量）**

- 是否有足够的存储空间？
- 是否有足够的资金？
- 如何处理所有数据？

**1.4 Existing data** **（已有数据）**

- 来源是什么？
- 是否与新数据结合？
- 你产生的数据与已有数据的关系？
 
**1.5 How data will be created or acquired** **（数据获取方式）**

- 时间（When?）
- 地点（Where?）
- 使用的标准或方法（Standard/Method）
- 命名规则与文件夹结构（Naming convention & folder structure）

**1.6 Short-term data management** **（短期数据管理）**

- Version control （版本控制）
- Backing up （备份）
- Security & protection （安全与保护措施）
- 责任人（Who is responsible?）
 
**1.7 How data will be processed** **（数据处理方式）**

- Software used （使用的软件）
- Algorithms （算法）
- Workflows （工作流程）

**1.8 Quality assurance & control** **（质量保证与控制）**

- 重复测量（Repeat measurements）
- 标准化数据采集（Standardised data capture）
- 数据同行评审（Peer review of data）

- 数据的文档化与报告（Documentation & reporting）
- 数据集的背景细节（Contextual details）
- 使用数据的重要信息（Critical information for usability）
- 示例：
    - 时间与空间细节（Temporal & spatial details）
    - 仪器（Instruments）
    - 参数（Parameters）
    - 单位（Units）
    - 文件（Files）

**3. Policies for access, sharing, reuse**  
（访问、共享与再利用的政策）  
**3.1 Obligations for sharing** **（共享义务）**

- 其他组织（Other organization）
- 法律要求（Legal）

**3.2 Details of data sharing** **（数据共享的细节）**

**3.3 Ethical/privacy issues** **（伦理与隐私问题）**
